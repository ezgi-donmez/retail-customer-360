# 📊 Dataset: dunnhumby – The Complete Journey

> **Bilgilendirme:**  
> GitHub dosya boyutu sınırları nedeniyle ham veri (*raw data*) dosyaları bu depoya dahil edilmemiştir. Projeyi çalıştırmak için aşağıdaki verileri yerel dizine (`data/raw/`) indirip yerleştirmeniz gerekmektedir.

---

## Ham Dosya Listesi ve İçerikleri (Raw Data Files)

| Dosya Adı | Yaklaşık Boyut | Açıklama |
| :--- | :--- | :--- |
| `campaign_desc.csv` | ~1 KB | Kampanya tanımları, başlangıç ve bitiş tarihleri |
| `campaign_table.csv` | ~94 KB | Hanelerin (`household_key`) hangi kampanyalarla eşleştirildiği bilgisi |
| `causal_data.csv` | ~679.5 MB | Ürünlerin mağaza içi sergilenme (*display*) ve broşür/posta (*mail*) görünürlük geçmişi |
| `coupon.csv` | ~2.7 MB | Kampanyalar ile ürünleri bağlayan kupon tanımları |
| `coupon_redempt.csv` | ~53 KB | Hanelerin kullandığı kuponların kullanım (*redemption*) kayıtları |
| `hh_demographic.csv` | ~43 KB | Hanelere ait demografik detaylar (gelir, aile büyüklüğü, yaş grubu vb.) |
| `product.csv` | ~6.2 MB | Ürün kataloğu; reyon, kategori, departman ve marka bilgileri |
| `transaction_data.csv` | ~138.4 MB | Hanelerin tüm alışveriş hareketleri (ürün ID, miktar, harcama, indirimler, zaman damgası) |
